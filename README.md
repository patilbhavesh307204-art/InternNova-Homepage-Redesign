# InternNova Homepage Redesign

A responsive homepage redesign created as a real-world web development project.

## Files
- `index.html` — homepage structure and content
- `style.css` — responsive styling and visual design
- `script.js` — navigation, FAQ accordion, CTA interaction, and scroll animations

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deployment
This project is ready to upload to GitHub and deploy using GitHub Pages.
